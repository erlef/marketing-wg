---
title: Gleam Team recaps participation in Github Security Lab
description: Gleam was invited to and participated in the 4th annual GitHub Secure Open Source Fund.
---
Gleam [reports](https://gleam.run/news/help-from-the-github-security-lab/) on their engagement with the GitHub Security Lab. [Louis Pilfold](https://github.com/lpil) recaps that Gleam entered the program in a good state and no vulnerabilities were found. Both of these are credited to Gleam's security priorities and collaboration with the EEF on security. It's a quick read, and whether you are a Gleamer or not, it is worth reading.
